Recursos y comunidad
Librerías de código abierto utilizadas
electronMIT
Framework principal que permite construir y ejecutar la aplicación de radio en el escritorio utilizando tecnologías web.
electron-builderMIT
Herramienta para empaquetar y generar los instaladores de la aplicación listos para su distribución.
@electron/rebuildMIT
Recompila módulos nativos de Node.js para asegurar su compatibilidad con la versión interna de Node que usa Electron.
better-sqlite3MIT
Librería rápida para SQLite3. Maneja la base de datos local (catálogos de canciones, pautas y horarios).
ffmpeg-staticGPL-3.0
Binarios precompilados de FFmpeg. Se utiliza para el procesamiento y análisis técnico de los archivos de audio.
fuse.jsApache-2.0
Librería de búsqueda aproximada. Permite buscar rápidamente pistas, artistas o álbumes en la biblioteca.
node-id3MIT
Lector y editor de metadatos. Extrae la información de las etiquetas ID3 (título, artista, etc.) de los audios.
cpal (Rust)Apache-2.0
Librería de entrada/salida de audio. Interfaz de bajo nivel con las tarjetas de sonido del sistema.
rodio (Rust)MIT / Apache-2.0
Librería principal de reproducción de audio. Maneja la mezcla, el control de los reproductores y el envío al canal de audio.
Symphonia (Rust)MPL-2.0
Motor de decodificación de audio 100% en Rust. Da soporte a MP3, FLAC, WAV, OGG Vorbis, AAC/M4A, ALAC, AIFF, MP2, CAF y ADPCM.
libc (Rust)MIT / Apache-2.0
Enlaces directos a funciones fundamentales del sistema operativo (usado para leer el reloj nativo).
rtrb (Rust)MIT / Apache-2.0
Estructura de memoria rápida (ring buffer) para transferir audio entre hilos sin interrupciones.
base64 (Rust)MIT / Apache-2.0
Permite codificar bloques de audio en texto plano para transmitirlos rápidamente hacia la interfaz.
