# Instalação e Primeiros Passos

O LF Automatizador foi projetado para ser fácil de instalar tanto no Windows quanto no Linux usando instaladores pré-compilados prontos para usar.

## Download Oficial

A maneira mais fácil e recomendada de obter o programa é baixando a versão mais recente na página oficial de *Releases* (Lançamentos) do GitHub. Isso garante que você sempre obterá a última versão estável.

👉 **[Baixe a última versão aqui](https://github.com/yosoyluisfernando/lf-automatizador/releases/latest)**

---

## Instalação no Windows

1. Na página de downloads, localize e baixe o arquivo que termina em `.exe` (por exemplo, `LF-Automatizador-0.9.12-win.exe`).
2. Após o download, clique duas vezes no arquivo para iniciar o instalador.
3. Siga as instruções na tela. O instalador configurará tudo automaticamente (incluindo os motores de áudio) e criará um atalho na área de trabalho.

## Instalação no Linux

Na página de downloads, você encontrará duas opções para o Linux: `.AppImage` e `.deb`.

**Opção A: AppImage (Recomendado)**
1. Baixe o arquivo `.AppImage`.
2. Clique com o botão direito no arquivo, vá para **Propriedades > Permissões** e marque a caixa "Permitir a execução do arquivo como um programa" (ou use `chmod +x arquivo.AppImage` no terminal).
3. Dê um clique duplo para abrir o programa imediatamente sem instalar nada.

**Opção B: Pacote DEB (Debian/Ubuntu)**
1. Baixe o arquivo `.deb`.
2. Instale-o clicando duas vezes nele (seu gerenciador de software será aberto) ou pelo terminal usando `sudo dpkg -i nome_do_arquivo.deb`.

## Configuração Inicial

Ao abrir o programa pela primeira vez, recomendamos ir em **Ferramentas > Biblioteca de Músicas** para configurar a sua pasta raiz. Falaremos mais sobre isso na seção de Gerenciamento de Biblioteca!
