# Installation and Getting Started

LF Automatizador is designed to be easy to install on both Windows and Linux using ready-to-use compiled installers.

## Official Download

The easiest and recommended way to get the program is by downloading the latest version from the official GitHub *Releases* page. This guarantees you will always get the latest stable version.

👉 **[Download the latest version here](https://github.com/yosoyluisfernando/lf-automatizador/releases/latest)**

---

## Installation on Windows

1. On the download page, find and download the file ending in `.exe` (e.g., `LF-Automatizador-0.9.12-win.exe`).
2. Once downloaded, double-click the file to start the installer.
3. Follow the on-screen instructions. The installer will automatically configure everything (including audio engines) and create a desktop shortcut.

## Installation on Linux

On the download page, you will find two options for Linux: `.AppImage` and `.deb`.

**Option A: AppImage (Recommended)**
1. Download the `.AppImage` file.
2. Right-click the file, go to **Properties > Permissions** and check the box "Allow executing file as program" (or use `chmod +x filename.AppImage` in the terminal).
3. Double-click to run the program immediately without installing anything.

**Option B: DEB Package (Debian/Ubuntu)**
1. Download the `.deb` file.
2. Install it by double-clicking it (your software manager will open) or via terminal using `sudo dpkg -i filename.deb`.
